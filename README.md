# Gloria Tetchouang | Portfolio

Personal portfolio of Gloria Tetchouang, a second-year Software Engineering student at the University of Ottawa, looking for a Winter 2027 co-op.

**Live site:** https://zyralein.github.io

## About the project

A responsive portfolio designed and coded from scratch, with a soft, pastel, slightly futuristic style.

## Features

- Glassmorphism layout with a single hero card
- 3D butterflies animated with three.js
- Interactive avatar that types code, follows the cursor, and comments on each section
- Scroll-triggered reveals and a navigation bar that stays on screen
- Project cards with browser-style windows
- Support for reduced motion and keyboard navigation

## Built with

- HTML, CSS, and JavaScript
- three.js
- Font Awesome
- Google Fonts (DM Sans and Inter)
- Hosted on GitHub Pages

## Run it locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ZyraLein/ZyraLein.github.io.git
   ```
2. Open `index.html` in your browser.
